# DNF MOD 管理器

文件级、可完全回滚的 DNF 补丁管理工具。免安装单文件，导入补丁 → 一键启用 → 一键还原。

> **v0.1.0 是预览版。** 开发全程在模拟的客户端目录里验证，**没有在正式服的真实 DNF 客户端上实机跑过**。
> 第一次使用请先用测试用的游戏目录，或先完整备份游戏目录。

## 它做什么

| 能力 | 说明 |
| --- | --- |
| 补丁库管理 | 导入文件 / 文件夹 / 拖拽导入，按 12 类落点自动归类，缩略图、搜索、排序、筛选 |
| 启用 / 停用 | 启用用独占复制（`COPYFILE_EXCL`），同名即报冲突，**绝不覆盖**已有文件 |
| 安装账本 | 每次写入都记账，「在装」面板可还原、强制移除记录、清理残留备份 |
| NPK 解析 | 解析 `NeoplePack_Bill` 索引，识别资源条目与落点，支持外部 NPK 认领 |
| 冲突与互斥 | 列出互斥/包含关系的变体（exclusive / subset + 相似度），提前告诉你谁会盖谁 |
| 载入优先级 | 补丁目录名前缀即优先级，界面里可直接提前 / 靠后 |
| bk2 等覆盖 | 可覆盖 `bk2/webm/ogg/mp3/wav/tga/dds/conf/tbl/ini/lua`，覆盖前先备份原件并校验备份哈希 |
| 预设 | 把一组启用状态存成预设，随时切换 |
| 更新重刷 | 补丁包更新后，失效的已装补丁一键重刷 |
| 体检 | 检查游戏目录、账本与实际文件是否对得上 |

## 它不做什么

明确不做、也不会加：

- 进程注入、内存修改、API Hook；
- 绕过或躲避 TP / ACE 反作弊的检测；
- 解密或编辑 NPK 内容，不修改官方文件本体；
- 联网、下载、遥测、自动更新检查（本机可完全离线运行）。

它只做一件事：把你的补丁文件复制进游戏目录的指定位置，并且随时能干净地撤回来。

## 运行要求

- Windows x64，免安装，双击即用（约 96 MB 单文件）；
- 不需要 .NET，不需要管理员权限——但如果游戏目录在受保护路径（如 `Program Files`）下，写入可能失败；
- 解 `.zip` 用系统自带 `tar.exe`（Win10 1803+）；解 `.rar` / `.7z` 需要本机装有 7-Zip；
- 启用 / 停用都要在**游戏未运行**时进行，程序检测到 `DNF.exe` 在跑会直接拒绝写入；
- 改完补丁需要重启游戏才会生效。

## 安全设计

- 写入前对目标路径做 realpath 穿透校验，杜绝符号链接逃逸到所选游戏目录之外；
- 相对路径消毒：拒绝 `..`、盘符、UNC、Windows 保留名；
- 停用只删「账本记过、且内容指纹吻合」的文件；指纹不匹配会拒绝删除并提示可能已被外部改动；
- 内容指纹：≤ 8 MB 的文件用哈希，更大的退化为「大小 + 修改时间」（避免 400 MB 的包卡住）；
- 每个写操作前有事务日志，异常退出后下次启动按日志逆序补偿回滚；
- 状态文件损坏时自动进入只读模式，不再做任何写操作。

## 首次运行提示

- **SmartScreen 蓝窗**：本程序未做代码签名，首次运行可能提示「Windows 已保护你的电脑」→ 点「更多信息」→「仍要运行」。
- **杀软误报**：Electron 便携包（自解压到临时目录）偶发被误报，属常见现象；你可以自行校验文件哈希后再用。
- 数据与备份都在 `%APPDATA%\dnf-mod-manager\` 下，卸载 = 删掉 exe + 这个目录。
